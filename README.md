# Chwila_Skupienia

Projekt strony internetowej udostępniającej narzędzia wspierające skupienie w pracy.
Posiada system rejestracji i logowania użytkowników zintegrowany z bazą danych w Firebase. Użytkownik posiada możliwość pracy/nauki z minutnikiem Pomodoro i korzystania z odtwarzacza muzyki. Strona profilu zawiera dane statystyczne na temat aktywności z minutnika, ranking czasu aktywności między znajomymi, edytowalną listę zadań do zrobienia oraz wyszukiwarnę innych użytkowników.
